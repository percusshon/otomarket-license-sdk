# Lv0: 購入証明ライセンスキー

> 用語集: **[やさしい用語集](./glossary.md)**。

**成功の合図**: 買い手が OtoMarket ライブラリで自分のキーを見られます。

Lv0 はデフォルトの、コード不要の方式です。OtoMarket が購入者にライセンスキーを発行し、購入者ライブラリに表示します。このキーは手動サポート時の購入証明として使えますが、商品そのものは activation を強制しません。

## OtoMarket が提供するもの

- 購入後に購入者へ表示されるライセンスキー。
- 購入者が後からキーを確認できるライブラリ保存。
- クリエイターや管理者がサポート時に確認できる商品所有記録。

SDK、API call、公開鍵、activation UI は不要です。

## クリエイターの手順

1. 商品に購入証明キーが必要な場合は、**Issue license key** を有効のままにします。
2. 購入後、キーは OtoMarket ライブラリで確認できることを購入者に伝えます。
3. 手動サポート時には、そのキーを購入証明として使います。

購入者向け文言の例:

> あなたの OtoMarket ライセンスキーは、購入後に OtoMarket ライブラリで確認できます。サポートや購入確認のために保管してください。

## 制限

Lv0 は、商品のコピー、共有、起動を止めるものではありません。アプリやプラグイン側で台数、期限、失効を確認したい場合は、Lv1 または Lv2 に進んでください。
