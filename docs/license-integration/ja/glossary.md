# ライセンス用語集（やさしい言葉）

ライセンス連携ガイドを読むための、前提知識なしで使える用語集です。

> たとえ話: **ライセンス**は**コンサートのチケット**のようなものです。**アクティベーション（認証）**は**入口でチケットを見せる**こと。**台数（座席）**は、そのチケットで**何台まで**入れるか。**オフライン猶予**は、チケット読取機がネットにつながらなくても、入口が**しばらくは覚えていて入れてくれる**ことです。

---

## 基本用語

### ライセンスキー

購入後に買い手が受け取るコードです（例 `OTOMARKET-XXXX`）。買った証拠になります。チケット番号のようなものです。

### productKey

その license が**どの商品向けか**を示す公開 ID です。OtoMarket では `Product.id` そのものです。アプリに埋め込んで問題ありません。秘密情報ではありません。

### アクティベーション（認証）

アプリがライセンスキーを OtoMarket に送り、「有効です」という返事をもらうことです。最初に入口でチケットを見せる動作に近いです。

### 台数（座席）

1つのライセンスで認証できる端末数です。「2台」なら2台の machine で使えます。上限に達すると `SEAT_LIMIT` が返ります。

### 期限（`expiresAt`）

ライセンスが使えなくなる日です。買い切りライセンスには期限がなく、サブスク型には期限があります。

### 失効（`REVOKED`）

ライセンスを無効化することです。たとえば返金後に行います。次のオンライン確認で `REVOKED` が返ります。

### machineId

端末1台を識別する、プライバシーに配慮した fingerprint です。個人情報ではなく hash です。誰であるかを保存せずに台数を数えるために使います。

## セキュリティ用語

### 公開鍵（`LICENSE_SIGNING_PUBLIC_KEY`）

ライセンスファイルが本物かを**検証する**ための鍵の片割れです。配布するアプリに埋め込んでも安全です。SDK には `Config.publicKeyPem` として渡します。

### 秘密鍵（`LICENSE_SIGNING_PRIVATE_KEY`）— **配布禁止**

もう片方の鍵です。**OtoMarket のサーバーだけ**がライセンスに署名するために使います。アプリ、doc、repo に絶対に入れないでください。

### 署名付きライセンストークン

activation 時にサーバーが返す、署名付きの小さなファイルです。アプリは公開鍵を使って**オフライン**で検証できるため、毎回インターネットに接続する必要はありません。

### 公開鍵セット（keyset / `kid`）

OtoMarket はクリエイターごとに別々の署名鍵を使うことがあります（万一どれか1つの鍵が漏れても、影響をそのクリエイターの商品だけに抑えるため）。その場合トークンに `kid`（鍵の名札）が付き、SDK が必要な公開鍵を `…/keys` から自動取得します。`kid` 無しの旧トークンだけが `publicKeyPem` を使い、`kid` 付きトークンは一致する keyset 鍵が必須です。取得済みキャッシュはオフライン利用できますが、初回取得前や鍵ローテーション直後はオンライン接続が必要です。

### オフライン猶予（`verifyAfter`）

オンライン再確認をせずに、キャッシュした license を信頼する期間です。買い切りは約14日、サブスクは課金周期以下です。なお SDK には**オフラインで信頼し続ける上限（既定 約30日）**もあり、最長でもその範囲で一度はオンライン再確認します（鍵漏洩時の悪用を抑えるため）。通常利用では自動で満たされ、ユーザーの手動操作は不要です。

## 技術ツール用語

### API（Layer 1 license API）

他のプログラムが呼び出す Web endpoint です。`/api/license/v1/activate`、`/verify`、`/deactivate` があります。アプリがインターネット越しに話しかける受付のようなものです。

### SDK

ライセンス処理を自分で書かずに済む、出来合いのコード部品です。OtoMarket の SDK は C++ で、`packages/license-sdk-cpp` にあります。3つの関数で完結します。

### 3つの関数

- `otoActivate(productKey, licenseKey, machineName)` — ここで認証します。
- `otoIsLicensed()` — 「今使ってよいか？」を確認します。起動毎に呼びます。
- `otoDeactivate()` — 座席を解放します。

### CMake / JUCE

CMake は SDK をプロジェクトに取り込むためのビルドツールです。JUCE はオーディオプラグインでよく使われる C++ framework です。OtoMarket SDK には、任意で使える JUCE adapter と既製の activation screen が含まれます。

### Sandbox

実購入なしで activation を試せる、安全なテスト商品とテストキーです。`productKey=otomarket-sandbox-license-sdk`、
`licenseKey=OTOMARKET-SANDBOX-LICENSE-SDK` を使います。

## 結果コード

| Code | 意味 |
| --- | --- |
| `SEAT_LIMIT` | すでに端末数の上限に達しています。 |
| `EXPIRED` | ライセンスの期限が過ぎています。 |
| `REVOKED` | ライセンスが無効化されています（例: 返金後）。 |
| `NOT_FOUND` | そのライセンスキーは存在しません。 |
| `PRODUCT_MISMATCH` | キーが別の商品向けです。 |
| `INVALID_REQUEST_BODY` | request が空または不正です。API には到達できています。 |
